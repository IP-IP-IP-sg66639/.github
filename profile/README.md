<h2>一、两个词说的不是同一件事</h2>
<p>家庭 IP 描述的是接入方式，地址来自家庭宽带线路。住宅 IP 描述的是地址属性，注册主体为住宅用途。前者讲怎么连上网，后者讲这个地址在数据库里被归为哪一类。</p>
<p>日常沟通里两者常被当同义词，因为多数家庭宽带的地址确实是住宅属性。但转售市场上，机房段被重新注册成住宅属性的情况不少，这时两个词就分家了。</p>
<h2>二、从接入方式看家庭 IP</h2>
<p>家庭宽带的典型形态是光猫加路由器，运营商分配地址，多数是动态的，重新拨号就变。要固定就得申请静态段，或让上游做地址绑定，这在住宅线路上并不普遍。</p>
<p>所以严格意义的家庭 IP 天然偏动态。市场上卖的所谓静态家庭 IP，多是上游做了绑定，或者根本是从机房段转过来的。购买时要问清地址的生命周期。</p>

<h2>三、海外 IP 的五种常见类型</h2>
<p>第一类是住宅 IP，属性为住宅，供给来自家庭线路。第二类是机房 IP，挂在 IDC 名下。第三类是移动 IP，走蜂窝网络。第四类是原生 IP，强调未被二次分配。第五类是广播 IP，注册地与落地不一致。</p>
<p>五类之间有交叉，一个地址可以既是住宅又是原生，也可以是机房加广播。分类的意义在于判断它在检测系统里会被归到哪一档，而不是拿来当营销词。</p>

<h2>四、三组最容易混的概念</h2>
<p>第一组是动态家庭与静态住宅。前者强调会变，后者强调不变，两者可以同时成立，也可以都不成立。第二组是原生与住宅，原生讲分配链路，住宅讲注册属性。</p>
<p>第三组是住宅与移动。移动地址来自蜂窝网络，属性上不属于住宅，但背后是真实手机用户，很多场景下比住宅段更受欢迎，价格也更高。</p>
<h3>为什么广播 IP 常被当成原生卖</h3>
<p>广播 IP 的注册地可以填任何地方，查询工具显示韩国，实际落地可能在别处。它满足原生的第一层条件，却不满足路由一致这一层，容易被包装成原生出售。</p>
<h2>五、按类型看适用面</h2>
<p>需要长期登录的，选原生住宅加独享。需要跑量抓取的，机房段加轮换。需要移动端呈现的，用移动段。只需要查看地区内容的，共享住宅或广播段都能凑合。</p>
<p>预算有限时，先保类型再保数量。一个靠谱的独享住宅地址，比五个来路不明的便宜地址有用。类型错了，数量再多也补不回来。</p>
<h2>六、术语表与判断顺序</h2>
<p>判断顺序建议固定为四步：查归属类型，查 ASN，查注册地与落地是否一致，查是否被二次分配。四步做完，一个地址的画像基本清楚，不用再听商家解释。</p>
<p>把这个顺序写成检查清单，每次采购前过一遍。清单不需要复杂，四行就够，关键是每次都做，而不是凭印象判断。</p>
<h2>常见问答</h2>
<h3>家庭 IP 和住宅 IP 可以互换使用吗？</h3>
<p>答：日常说法里可以，严格说不行。家庭 IP 指接入方式来自家庭宽带，住宅 IP 指注册属性。买时问清是家庭线路拨号出来的，还是机房段改了注册信息。</p>
<h3>静态住宅 IP 会不会变？</h3>
<p>答：正规渠道承诺固定的一般在合同期内不变，实际仍可能因上游调整而变更。采购时问清变更频率与是否免费更换，并把这条写进订单。</p>
<h3>原生 IP 比住宅 IP 更好吗？</h3>
<p>答：两者不是同一维度。原生强调分配链路完整，住宅强调注册属性。一个地址可以两者兼具，也可以只满足一个，要看业务更在意哪项。</p>
<h3>移动 IP 为什么比住宅 IP 贵？</h3>
<p>答：供给少，蜂窝网络的地址资源由运营商集中管理，能对外提供的量有限。加上移动端场景对地址真实性要求高，价格自然上去了。</p>
